## 2 已实现内容

- `common.api`：`ApiResponse`、`PageResponse`、`FieldViolation`、`ValidationErrorData`。空列表保持成功和空集合，分页默认第 1 页、每页 20 条，上限 100。
- `common.exception`：`BusinessException` 保留 `HttpStatus` 和字符串业务码，支持 A 定义领域码；统一处理 400、401、403、404、409、500。
- 字段校验失败返回 `data.errors`，每项仅含字段名和提示；不输出被拒绝的字段值。JSON 无法解析等非字段错误的 `data` 为 `null`。
- 数据库约束和乐观锁异常返回 409；未知异常返回 500 和通用提示，服务端只记录异常类型和请求标识，不直接记录原始异常消息。
- MVC 405、415 等其他协议错误保留原 HTTP 状态和必要响应头，使用 `COMMON_HTTP_ERROR`。这是技术错误兜底，不改变契约中的六类业务错误语义。
- `common.validation`：分页格式、边界及偏移量溢出检查；正整数 ID；批量 ID 数量检查和去重；文本长度；带偏移量时间转 UTC、起止顺序；排序字段映射与方向白名单。
- 批量 ID 默认不允许空集合；角色集合覆盖等清空场景可显式传入 `allowEmpty=true`。批量和文本具体上限由各业务接口指定，不在公共层假设统一业务限制。
- `common.context`：合法客户端 `X-Request-Id` 复用（1～64 位字母、数字、下划线、连字符），其他情况生成 UUID；响应头、响应体及 MDC 使用同一标识；正常和异常退出均清理线程上下文，错误/异步再次分派时复用原请求标识。

业务 Controller 仍需显式调用响应工厂；没有启用自动包装所有返回值的切面。DTO 应使用 `@Valid` 和 Bean Validation 注解，领域状态校验仍由对应业务模块执行。`BusinessException` 的 message 属于公开文本，不能直接传入数据库异常消息或请求正文。

## 3 A/B 接入示例

```java
import com.zachery.cms.common.api.ApiResponse;
import com.zachery.cms.common.api.PageResponse;
import com.zachery.cms.common.exception.BusinessException;
import com.zachery.cms.common.validation.PageQuery;
import org.springframework.http.HttpStatus;

PageQuery query = PageQuery.parse(queryParameters);
// records 和 total 由当前业务模块按相同筛选条件查询得到。
return ApiResponse.ok(new PageResponse<>(records, total, query.page(), query.size()));

// 状态冲突示例（独立于上面的返回语句）：
throw new BusinessException(HttpStatus.CONFLICT, "ARTICLE_STATUS_CONFLICT", "文章状态冲突");
```

以上为调用片段，不是新增的文章业务接口。`RequestValidation.sort` 接受服务端提供的字段名映射，SQL 排序列只能使用映射结果；业务模块自行补上稳定排序用的 ID，并设置默认排序。

## 5 复现方式

在 E 盘项目根目录的 PowerShell 中设置本次进程的临时目录和 Maven 缓存，再执行验证：

```powershell
$env:TEMP = Join-Path (Get-Location).Path 'runtime\tmp'
$env:TMP = $env:TEMP
New-Item -ItemType Directory -Force -Path $env:TEMP | Out-Null
$env:MAVEN_OPTS = "-Djava.io.tmpdir=$env:TEMP -XX:-UsePerfData"
mvn -B -ntp -gs scripts/settings.xml -s scripts/settings.xml "-Dmaven.repo.local=.cache/m2" "-DargLine=-Djava.io.tmpdir=$env:TEMP -XX:-UsePerfData" clean verify
```

本次验证复用了 E 盘已有 Maven 缓存，通过用户指定的本机代理下载缺失依赖；代理设置放在仓库外，未写入项目配置。`-gs` 与 `-s` 显式选择设置文件，避免本机旧全局配置影响验证。上述复现命令默认直连 Maven Central，需要代理时使用自己的本机 Maven 设置。
