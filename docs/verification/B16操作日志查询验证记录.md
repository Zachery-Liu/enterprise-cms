# B-16 操作日志查询验证记录

日期：2026-10-11。分支 `feat/operation-log-query`，基于 B-15 `f9abceb`。本轮范围为只读查询接口与 ApiFox 验收集合，不改日志表或既有业务权限规则。

## 实现与环境

新增 `GET /api/operation-logs`，使用 `cms:log:read` 权限。支持分页、操作者 ID/历史名称、模块、动作、结果和含时区的时间范围；固定按时间及 ID 倒序。使用 MyBatis-Plus 参数绑定与数据库分页；只读 REPEATABLE_READ 事务覆盖总数和本页查询，名称等值比较沿用 MySQL 排序规则。

实际环境：Microsoft OpenJDK 17.0.20.1+1、Maven 3.9.6、Spring 6.2.15、MyBatis-Plus 3.5.10、MySQL 8.0.44、外部 Tomcat 10.1.60。没有 Spring Boot。

## 覆盖内容

- 默认分页、第二/末页、超出最后一页、超大合法页码及空集合。
- 同一毫秒时间的日志按 ID 倒序，静态数据分页无重复。
- 各筛选项单独生效与全部条件 AND 组合；单边时间范围、偏移量归一及毫秒边界。
- 页码/页大小/ID/结果/编码格式、时间缺少时区或精度超限、UTC 年份范围、倒置时间范围、未知/重复参数返回 400。
- 参数绑定阻止名称被当作 SQL 或 LIKE 通配符。
- 匿名日志保留 null 操作者；账号改名及逻辑删除不覆盖历史名称快照。
- 未登录 401、无权限 403；同 Session 撤销/恢复授权立即生效，ADMIN 无隐式绕过。
- 权限/角色停用、账号停用的访问控制；账号停用导致 Session 失效。
- 查询不新增审计行；POST/PUT/PATCH/DELETE 无日志修改入口。
- 响应 requestId、UTC 时间、no-store 缓存头及无密码/会话字段。
- 实际部署 WAR 的认证、注册、授权/撤权、会话轮换流程继续通过；新增真实 HTTP 的日志组合查询、数量及 UTC 断言，并验证 401/403/400。

首次测试修正了用例对统一校验错误字段的误写（实际是 `data.errors`）；全量回归发现权限入口数量从 6 增至 7，已同步保护入口枚举断言，未移除权限验证。修正后全量、真实 MySQL 和外部 WAR 均通过。
