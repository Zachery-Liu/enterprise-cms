## 可复现的隔离预览

在项目根目录启动：

```sh
node src/test/browser/content-b-fixture.cjs
```

脚本打印回环地址，访问其 `/cms/content/public.html` 查看公开列表，或 `/cms/content/index.html` 查看编辑器。使用任意非空的测试账号、密码登录；登录只作用于测试服务，不访问真实数据库。首次图片上传故意失败以验证重试；标题包含“冲突”时故意模拟一次版本冲突。

此服务只用于人工浏览器验收；不是生产实现，不提供真实文件存储、清洗或权限保证。原 `content-pages.cjs` 使用旧 textarea 及旧公开布局选择器，本次未将其当作已通过的回归套件。

## 追加：首页改为 WordPress 博客风格

参考 WordPress 官方 Twenty Sixteen 的横向刊头、文章流与侧栏结构（https://wordpress.org/themes/twentysixteen/），在现有 Vue 组件中实现，不引入 WordPress 或主题依赖。

- 站点大刊头、暖白背景、宋体标题、砖红强调色；移除原来的宣传式首页标题和顶部长筛选表单。
- 首页最新一篇文章重点展示，其余文章连续排列；侧栏包含站点介绍、搜索、分类和文章索引。
- 文章详情同步标题字体和站点色彩；手机端改为单列，侧栏自然排列到文章流之后，导航可以跳到分类区域。
- 搜索表单输入与已应用条件分离，输入时不会提前改变结果标题和文章布局；筛选后滚回结果区。
- 测试服务增加 4 篇公开样本、3 个分类，生产组件中没有写入样本文章。
- 类型检查、生产构建、补丁检查通过；人工验证分类筛选、侧栏搜索、详情/返回链接、390px 无横向溢出及导航到分类目录；最终控制台无 warn/error。
- 新截图：`output/playwright/b-wordpress-home-desktop.jpg`、`output/playwright/b-wordpress-home-mobile.jpg`。
- 本次仅调整公开界面；真实图片、分类接口等原有待 A 联调项保持不变，未部署 WAR。
