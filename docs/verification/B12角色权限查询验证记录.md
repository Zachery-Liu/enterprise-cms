## 实际验证范围

| 测试场景 | 结果 |
| --- | --- |
| 角色、权限目录及角色详情 | 排序稳定；目录可展示停用状态；删除对象不展示 |
| 无角色、多角色、重复输入 ID | 映射正确，输入 ID 去重，空组保留，结果不可修改 |
| 停用或删除账号、角色、权限 | 不计入有效角色和权限 |
| 空输入及 Mapper 防御 | Service 不执行 SQL；Mapper 的空/null 输入不读取全部关系 |
| 非正 ID、null、超过 500 项（含重复 ID） | 查询前拒绝，不执行 SQL |
| 多角色权限并集 | 权限去重；删除用户角色或角色权限关系后重新查询立即生效 |
| 重复关系插入 | H2 组合唯一约束拒绝；查询结果未重复 |
| 四个管理查询接口 | 未登录 401、缺权限 403、具备对应权限 200 |
| DTO、requestId、无效 ID 和不存在对象 | 五字段展示结构、响应标识一致、400/404 正确 |
| 同一会话撤销权限 | 下一请求 403；ADMIN 无隐式放行；普通角色获权限后可访问对应接口 |
| 停用角色、停用账号 | 前者拒绝授权，后者返回 401 并使会话失效 |

本批 MockMvc 测试经过真实 Spring MVC、会话认证拦截器、查询 Service、MyBatis XML 和 H2；仅使用测试会话模拟已登录状态，不重复测试密码登录。已有 B-09 的真实本机 HTTP 会话测试同时纳入此次全量回归。

## 批量查询次数证据

测试专用 MyBatis Executor 拦截器记录真实查询调用，正式代码和打包产物不含此计数器。每次计数均覆盖一次完整 Service 调用：

| 数据和调用 | 实测查询次数 |
| --- | --- |
| 60 个用户，30 人有 2 个角色、30 人有 1 个角色；批量读取角色 | 1（`selectRolesForUsers`） |
