不把三个集合无条件顺序连跑：B13 可能修改 B11/B16 的账号授权。每个集合使用独立测试对象，运行前清除上一个场景 Cookie，并确认权限前置条件。

## 4 复验顺序

1. 确认 JDK 17、传统 SSM 配置、空测试库及初始化顺序；A 内容 SQL 未验收前不声称全项目空库可部署。
2. 执行 mvn clean verify。默认常规测试使用独立 H2，不代表真实 MySQL。
3. 显式运行 MySQL *IT 时每组使用新的空库；它们会建表并清理测试数据。不能让多个初始化用例共用同一个非空库顺序执行。
4. 将最新 WAR 部署外部 Tomcat，在专用 HTTP 库运行 ExternalTomcatIT；环境变量见部署文档。
5. 人工运行集合并记录结果，再接真实 A 内容接口。
6. 失败时保存原始日志和 requestId，修复后运行相关专项及必要回归，更新实际结果。
