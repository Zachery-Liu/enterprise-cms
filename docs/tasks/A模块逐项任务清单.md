## 1 本轮前提与边界

以 `origin/feature/security@dff0cca` 已交付业务为参考；`origin/feature/content@dde44fb` 只有需求文档。A 旧实现不再作为开发基础，旧文件可归档，但本计划不授权自动删除或重置本地内容。全部任务待执行，不把旧设计或 B 历史测试视为本轮验收。

禁止 Spring Boot。B 主维护 POM、容器、MVC、数据源、事务、Mapper 扫描、公共插件与部署，A 接入其传统 SSM 工程。A 不重写身份认证、权限、公共响应和通用日志，不访问 B 的 Mapper。A 负责 `cms_category`、`cms_article`、`cms_article_status_history`。

依据：[A/B 分工](../A与B模块任务分工.md)、[B 任务清单](B模块逐项任务清单.md)、[公共契约](../design/B模块公共契约.md)。旧 A 架构和数据库设计作为重新评审输入，不能直接认定已完成。

## 2 里程碑与执行顺序

| 里程碑 | 任务 | 退出条件 |
| --- | --- | --- |
| AM0 设计与基线 | A-00、A-01、A-M00 | 内容规则与 SQL 确定，B 新工程可部署并接入 |
| AM1 内容基础 | A-02～A-04 | 分类、文章、分页与真实身份可用，分类完成 B-14 权限联调 |
| AM2 生命周期 | A-05、A-06 | 状态历史、批量事务、权限与日志符合契约 |
| AM3 质量与联调 | A-07、A-08 | 测试、优化、页面和真实 HTTP 流程通过 |
| AM4 交付 | A-09 | 空库部署和个人材料可复现 |

```text
B 执行 B-M01～B-M05 ← 同期 A 执行 A-00/A-01
  -> B-M06 交付说明 -> A-M00 接入
  -> A-02 分类 / B-14 权限联合验证
  -> A-03 文章 -> A-04 查询
  -> A-05 生命周期 / B-15 日志联合验证
  -> A-06 批量发布 -> A-07 测试优化
  -> A-08 页面联调 -> A-09 交付
```

领域与 SQL 设计不必等待工程迁移。Service 规则可先开发，但未接入权限与日志的接口不得标为完成；临时保护须与 B 约定并在正式验收前替换，不使用权限空实现。

## 3 逐项任务

### A-M00 接入传统 SSM 工程

**依赖：** B-M01～B-M05 验收通过，B-M06 提供接入说明。

- [ ] 从 B 验收通过的提交建立新的 A 分支，记录提交和版本，不混入本地替代认证实现。
- [ ] 本机部署外部 Tomcat WAR，验证登录、当前用户、CSRF、requestId 和统一响应。
- [ ] 确认 content 组件与 Mapper/XML 扫描、统一分页/乐观锁插件和审计填充配置。
- [ ] 验证基于部署上下文路径的 API 地址与 Session Cookie。

**产物：** A 本机接入记录和开发环境说明。

**验收：** A 可以复用真实公共能力开发，不建立第二套启动、数据源或登录配置。

### A-00 重做内容领域与接口设计

**依赖：** 无，可与 B 迁移同步。

- [ ] 明确分类、文章、状态历史，固定六种状态及合法转换表。
- [ ] 确定统一 ArticleLifecycleService，普通编辑 DTO 不接受文章状态或操作者覆盖。
- [ ] 定义分类、文章、查询、提交、审核、发布、下架接口及输入输出。
- [ ] 按 B 公共契约固定 read/create/edit/delete/submit/audit/publish/offline 权限编码。
- [ ] 约定下架后重新编辑流程、退回原因、批量全成全败及公开查询边界。
- [ ] 明确 B-14 权限与 B-15 日志接入点，区分 A 状态历史与 B 操作日志。

**产物：** 修订后的 A 架构、状态表、接口及权限对照表。

**验收：** 业务规则无多处状态写入入口，公共接口使用远端实际类型。

### A-01 内容数据库与 SQL 验证

**依赖：** A-00、B 用户主键与审计字段契约。

- [ ] 重新评审或重做三张内容表、索引、外键、字段字典与 E-R 图。
- [ ] 分类根节点、版本号、逻辑删除与 UTC 审计字段统一。
- [ ] 作者、审核人、操作者关联 B 的用户主键；保留历史引用。
- [ ] 修复或替换 `sql/002_content_schema.sql` 中已记录的自指 CHECK 建表阻塞，并落实自指及循环关系业务校验。
- [ ] 在目标 MySQL 空库按身份表、内容表、初始化数据顺序实际执行，验证约束与重复执行策略。
- [ ] 如旧内容设计被整体废弃，更新正式执行脚本与文档，旧脚本不再留在安装入口。

**产物：** 内容 SQL、数据设计及真实数据库验证记录。

**验收：** 空库建表成功，外键正确；不能以 H2 通过替代 MySQL 验证。

### A-02 多级分类与内容持久层

**依赖：** A-M00、A-01；B-14 是接口最终验收依赖。

- [ ] 建立内容 Entity、Mapper、XML、DTO、VO 和 Service，验证扫描与审计填充。
- [ ] 实现树查询、新增编辑、移动排序、启停和删除。
- [ ] 阻止移动到自身或后代，校验无效父节点；有子节点或有效文章引用时拒绝删除。
- [ ] 一次查询后组装树或采用批量方案，避免逐节点查询。
- [ ] 分类读写接口接入 B 权限切面，作为第一次 A/B 权限联调样例。

**产物：** 分类实现、接口和正常/异常用例。

**验收：** 功能与循环、引用、权限边界通过；未登录 401、无权限 403。

### A-03 文章基础管理

**依赖：** A-02、B-10 真实当前用户。

- [ ] 实现新建草稿、详情、编辑和逻辑删除，作者来自 CurrentUserContext。
- [ ] DTO/VO 与 Entity 分离，客户端不能覆盖状态、作者或审计操作者。
- [ ] 只在约定合法状态编辑，落实下架后重新编辑规则。
- [ ] 使用版本号和条件更新，冲突返回 409；不绕过已有逻辑删除配置。
- [ ] 落实正文保存与显示的脚本注入防护。
- [ ] 在 B-15 交付后接入关键写操作日志。

**产物：** 文章基础接口与回归用例。

**验收：** 身份真实、旧版本不能覆盖新数据，已发布文章不能直接编辑。

### A-04 文章查询、分页与作者展示

**依赖：** A-03、B 统一分页配置。

- [ ] 实现数据库分页、标题/分类/状态/作者/时间组合筛选。
- [ ] 排序字段用白名单映射，增加稳定次排序键并限制页大小。
- [ ] 使用 ApiResponse/PageResponse 和 B 的统一校验与错误语义。
- [ ] 使用 UserReader.findByIds 批量读取本页作者；单批上限 500，不直接访问 B Mapper。
- [ ] 停用作者仍展示历史信息；缺失作者使用占位，禁止循环补查。

**产物：** 查询接口、分页筛选与作者展示用例。

**验收：** 总数和分页正确，非法参数被拒绝，不产生逐文章查作者的 N+1。

### A-05 审核发布生命周期与状态历史

**依赖：** A-03；规则可先开发，最终验收依赖 B-14/B-15。

- [ ] 实现提交、待审、通过、退回、发布、下架及约定的重新编辑。
- [ ] 退回原因必填，审核人与操作人来自真实当前用户。
- [ ] 单一生命周期 Service 写状态；SQL 同时校验 ID、原状态和版本。
- [ ] 文章状态和状态历史同事务提交，失败整体回滚。
- [ ] 公开 GET 声明 AnonymousAccess，只返回未删除的 PUBLISHED 文章。
- [ ] 接入权限与日志注解，验证编辑越权审核、重复和并发操作。

**产物：** 生命周期服务、状态历史、接口和流程测试。

**验收：** 合法转换成功，非法/并发转换返回 409，公开范围及权限正确。

### A-06 批量发布与事务

**依赖：** A-05。

- [ ] 限制最多 50 条，拒绝重复 ID，批量检查存在性、状态和权限。
- [ ] 在同一事务执行更新及状态历史；处理中途异常与并发版本冲突。
- [ ] 对失败对象给出明确原因，不暴露 SQL 或堆栈。
- [ ] 与 B 验证业务回滚不留下虚假成功日志。

**产物：** 批量发布及故障回滚用例。

**验收：** 全部合法全部成功，任一失败整批内容与历史回滚。

### A-07 查询优化与内容测试

**依赖：** A-02～A-06。

- [ ] 用普通 Spring Test 测试分类循环、引用、文章冲突、状态转换、并发和批量回滚。
- [ ] 记录文章列表关联分类/作者的 SQL 次数及优化前后数据一致性。
- [ ] 验证联表或批量方案不会改变分页总数；保存数据规模、执行计划或耗时证据。
- [ ] 导出正常、异常及越权 ApiFox 用例，不保留故意低效的正式实现。

**产物：** 自动化测试、优化证据和接口集合。

**验收：** 实际运行通过，证据可复现，不采用 Boot 测试 API。

### A-08 页面与联合验收

**依赖：** A-07、B-14/B-15。

- [ ] 实现 A 负责的分类、文章、待审核和发布操作页面。
- [ ] 按真实 Session/CSRF 接入，按钮展示与服务端权限一致。
- [ ] 使用目标 MySQL、外部 Tomcat 和 ApiFox 验证登录至下架完整流程。
- [ ] 验证停用、权限撤销、越权审核、CSRF 拒绝、匿名查询及日志真实结果。

**产物：** 页面与 A/B 联调记录。

**验收：** 正常和越权流程可重复执行，后台接口保护不依赖隐藏按钮。

### A-09 交付与个人材料

**依赖：** A-08。

- [ ] 更新架构、数据库、接口、流程图与测试说明。
- [ ] 保留 Git、AI 采用范围、人工修改、真实排错及个人 SQL 优化记录。
- [ ] 与 B 完成干净环境 SQL、配置、WAR 构建部署及演示验证。

**产物：** A 报告章节、个人总结、过程证据和联合部署记录。

**验收：** 文档与实际一致，另一环境可完成主流程，A 能解释状态机、事务与优化。
