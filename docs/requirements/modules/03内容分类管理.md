# 内容分类管理模块需求分析

| 项目 | 内容 |
| --- | --- |
| 模块负责人 | A |
| 主要参与者 | 内容编辑、管理员 |
| 上游依赖 | 当前用户、权限 AOP、统一异常 |
| 下游使用方 | 文章创建、文章筛选、发布前校验 |

## 1 模块目标

本模块通过树形分类组织文章，为文章创建、查询和发布提供稳定的分类引用。分类停用、删除和移动不能静默破坏已有文章或形成循环层级。

“分类”和企业级需求中的“栏目”在课程 MVP 中统一处理，不再建设另一套栏目树。

## 2 分类对象

分类至少包含：稳定 ID、父分类 ID、名称、排序值、状态、逻辑删除标识和公共审计字段。具体字段长度和类型在数据字典中确定。

### 2.1 分类状态

| 状态 | 含义 | 对文章的影响 |
| --- | --- | --- |
| `ENABLED` | 可正常使用 | 允许新文章绑定，允许查询和发布 |
| `DISABLED` | 暂停使用 | 禁止新绑定和新发布；历史数据保留 |

逻辑删除不作为可由客户端任意设置的分类状态。

## 3 功能需求

| 编号 | 优先级 | 需求 | 业务结果 |
| --- | --- | --- | --- |
| CAT-01 | P0 | 分类树查询 | 返回完整或指定根节点下的分类树 |
| CAT-02 | P0 | 新增分类 | 在合法父分类下创建分类 |
| CAT-03 | P0 | 编辑分类 | 修改名称和必要展示信息 |
| CAT-04 | P0 | 移动分类 | 修改父级且不形成循环 |
| CAT-05 | P0 | 分类排序 | 调整同级分类显示顺序 |
| CAT-06 | P0 | 分类启停 | 控制是否允许新绑定和发布 |
| CAT-07 | P0 | 删除分类 | 满足无子节点、无有效引用时逻辑删除 |
| CAT-08 | P0 | 分类有效性校验 | 为文章保存和发布提供统一检查 |

## 4 树形结构规则

1. 根分类使用统一表示方式，不能同时混用 `NULL`、`0` 和特殊根记录。
2. 父分类必须存在、未删除并且可作为父节点使用。
3. 分类不能以自身为父分类。
4. 分类不能移动到自己的任意后代节点下。
5. 移动分类时，其所有后代随节点整体移动。
6. 分类树查询不得为每个节点单独访问数据库。
7. 返回同级分类时，先按排序值，再按稳定唯一字段排序。
8. 是否限制最大层级属于待确认项；没有业务要求时不设置过小的固定层级。

## 5 名称和排序规则

1. 分类名称为必填项，去除首尾空白后不能为空。
2. 同一父分类下是否允许重名必须固定。课程 MVP 建议不允许，并由数据库或事务内校验兜底。
3. 不同父分类下允许使用相同名称。
4. 排序值必须在约定范围内；排序相同时使用 ID 作为稳定次排序键。
5. 排序接口可以只修改一个分类的排序值，不要求首期实现复杂拖拽重排算法。

## 6 启停规则

1. 启停分类需要 `cms:category:manage` 权限。
2. 停用分类后，历史文章和后台查询仍保留分类信息。
3. 停用分类禁止新文章绑定，也禁止已审核文章首次发布。
4. 停用分类不自动下架其中已经发布的文章，避免一次配置引发大范围线上变化。
5. 若业务需要下架已有文章，应由发布人员显式执行文章下架。
6. 启用子分类前，其父分类必须处于可用状态。

## 7 删除规则

1. 删除采用逻辑删除。
2. 分类存在未删除子分类时拒绝删除。
3. 分类存在未删除文章引用时拒绝删除，包括草稿和已下架文章。
4. 删除失败应返回阻止删除的原因，不自动迁移文章或级联删除子分类。
5. 已删除分类不出现在普通分类树和文章选择列表中。
6. 逻辑删除后的同名分类是否允许重新创建，应与唯一约束保持一致。

## 8 权限

| 操作 | 权限 |
| --- | --- |
| 查询分类树和分类详情 | `cms:category:read` |
| 新增、编辑、移动、排序、启停、删除 | `cms:category:manage` |

文章保存时的分类有效性检查属于文章业务的一部分，不要求调用者额外拥有分类管理权限。

## 9 异常与边界场景

| 场景 | 预期结果 |
| --- | --- |
| 父分类不存在 | 404 或明确业务错误，不创建分类 |
| 父分类已停用 | 拒绝创建或启用子分类 |
| 分类移动到自身 | 409，树结构不变 |
| 分类移动到后代 | 409，树结构不变 |
| 同级名称重复 | 409 |
| 删除含子分类的分类 | 409，并说明存在子分类 |
| 删除被文章引用的分类 | 409，并说明存在文章引用 |
| 停用已含发布文章的分类 | 分类停用，线上文章不自动下架 |
| 查询空分类树 | 返回空集合，不返回 `null` 或异常 |

## 10 验收标准

- 可以创建至少三级分类并正确返回树结构。
- 修改父级不会形成自身引用或间接循环。
- 分类排序结果稳定，刷新后保持一致。
- 停用分类不能绑定新文章，也不能用于新发布。
- 有子分类或文章引用时不能删除。
- 分类树查询不存在逐节点 N+1。
- 所有写操作接入权限和操作日志。

## 11 不在本阶段范围

- 分类继承权限。
- 多站点独立分类树。
- 分类模板、SEO 和导航配置。
- 分类批量迁移和跨站复制。
