# 文章内容管理模块需求分析

| 项目 | 内容 |
| --- | --- |
| 模块负责人 | A |
| 主要参与者 | 内容编辑、审核人员、发布人员 |
| 上游依赖 | 用户认证、角色权限、内容分类、统一异常 |
| 下游使用方 | 审核发布、操作日志、公开文章查询 |

## 1 模块目标

本模块负责文章正文及其基础属性的创建、维护、查询和删除，是 CMS 的核心业务模块。文章管理与审核发布共用同一文章状态机，但普通编辑接口不能直接修改状态。

课程 MVP 使用单篇文章记录保存当前正文和状态，通过乐观锁防止并发覆盖。完整正文版本库属于后续扩展。

## 2 文章对象

文章至少包含以下业务信息：

| 信息 | 说明 |
| --- | --- |
| 标题 | 列表和详情展示的文章名称 |
| 摘要 | 可选的简短内容说明 |
| 正文 | 文章主体，可包含受控富文本 |
| 分类 | 关联一个有效内容分类 |
| 作者 | 创建文章的登录用户 |
| 状态 | 草稿、审核中、退回、通过、发布或下架 |
| 审核信息 | 最近审核人、时间和退回原因 |
| 发布时间 | 最近一次成功发布时间 |
| 乐观锁版本 | 检测并发编辑和状态变化 |
| 逻辑删除 | 区分业务删除与物理删除 |
| 审计字段 | 创建人、创建时间、更新人和更新时间 |

## 3 功能需求

| 编号 | 优先级 | 需求 | 业务结果 |
| --- | --- | --- | --- |
| ARTICLE-01 | P0 | 新增文章 | 创建一篇处于草稿状态的文章 |
| ARTICLE-02 | P0 | 编辑文章 | 修改允许编辑状态的文章并检测并发冲突 |
| ARTICLE-03 | P0 | 文章详情 | 返回文章、分类、作者和状态信息 |
| ARTICLE-04 | P0 | 文章分页 | 按权限返回稳定分页结果 |
| ARTICLE-05 | P0 | 多条件检索 | 按标题、分类、状态、作者和时间筛选 |
| ARTICLE-06 | P0 | 多维排序 | 使用受控排序字段返回稳定结果 |
| ARTICLE-07 | P0 | 逻辑删除 | 删除允许删除的文章 |
| ARTICLE-08 | P0 | 并发控制 | 阻止旧版本请求覆盖新数据 |
| ARTICLE-09 | P0 | 富文本安全 | 防止危险脚本进入受信任输出 |
| ARTICLE-10 | P1 | 恢复删除文章 | 管理员在规则允许时恢复逻辑删除文章 |

## 4 新增规则

1. 新建文章必须具备 `cms:article:create` 权限。
2. 标题、正文和分类为必填项；摘要是否必填由产品约定，课程 MVP 建议可选。
3. 标题去除首尾空白后不能为空，最大长度由数据字典规定。
4. 分类必须存在、未删除且处于启用状态。
5. 作者和创建人从当前登录用户获取，客户端传入值无效。
6. 新建文章状态固定为 `DRAFT`，客户端不能指定其他初始状态。
7. 初始乐观锁版本由服务端或数据库生成。

## 5 编辑规则

1. 编辑需要 `cms:article:edit` 权限。
2. 只有 `DRAFT` 和 `REJECTED` 状态可以修改标题、摘要、正文和分类。
3. 请求必须携带客户端最近读取的版本号。
4. 更新时同时匹配文章 ID、允许状态、逻辑删除标识和版本号。
5. 匹配失败时应区分记录不存在与版本或状态冲突；冲突返回 409。
6. 编辑成功后增加乐观锁版本号并更新审计字段。
7. 退回文章重新编辑后，可保留上一条退回原因供用户参考，但不能误认为已经重新审核。
8. 已审核通过、已发布和审核中的文章不能通过普通编辑接口修改。

## 6 查询规则

### 6.1 后台列表

后台列表需要 `cms:article:read` 权限，至少支持：

- 标题模糊匹配。
- 分类精确筛选。
- 文章状态筛选。
- 作者筛选。
- 创建或更新时间范围筛选。
- 页码和页大小。
- 创建时间、更新时间和发布时间排序。

查询规则：

1. 使用数据库分页，页大小设置合理上限。
2. 排序字段使用服务端白名单映射，方向只能为升序或降序。
3. 默认按更新时间降序、文章 ID 降序，保证分页顺序稳定。
4. 普通查询默认过滤逻辑删除数据。
5. 列表展示分类名和作者名时，不得逐篇查询关联对象。
6. 无结果时返回空集合及正确的总数，不返回异常。

### 6.2 文章详情

1. 后台详情需要 `cms:article:read` 权限。
2. 返回文章正文、分类、作者、状态、审核信息和审计时间。
3. 不返回数据库内部字段、密码信息或不必要的用户隐私数据。
4. 逻辑删除文章对普通后台详情返回 404。
5. 公开文章详情由审核发布模块定义，只能读取发布状态文章。

## 7 删除和恢复规则

1. 删除需要 `cms:article:delete` 权限并采用逻辑删除。
2. `DRAFT`、`REJECTED` 和 `OFFLINE` 允许删除。
3. `PENDING`、`APPROVED` 和 `PUBLISHED` 不允许直接删除。
4. 已发布文章必须先下架，再执行删除。
5. 删除操作不物理删除作者、分类和日志关系。
6. 恢复属于 P1；若实现，只允许管理员恢复且需要确认原分类仍然有效。

## 8 富文本安全规则

1. 文章正文不得信任客户端提交的 HTML。
2. 项目必须选择并记录一种明确策略：保存前清洗，或输出前按白名单清洗。
3. 至少处理脚本标签、事件属性、危险协议链接和嵌入式危险内容。
4. 管理后台预览和公开接口使用相同的安全边界。
5. 安全清洗不能只依靠前端编辑器。

## 9 权限

| 操作 | 权限 |
| --- | --- |
| 后台列表和详情 | `cms:article:read` |
| 新增 | `cms:article:create` |
| 编辑 | `cms:article:edit` |
| 逻辑删除 | `cms:article:delete` |

提交、审核、发布和下架权限见审核发布模块。

## 10 异常与边界场景

| 场景 | 预期结果 |
| --- | --- |
| 标题或正文为空 | 400 |
| 绑定不存在、删除或停用分类 | 拒绝保存 |
| 客户端指定作者和发布状态 | 忽略或拒绝非法字段 |
| 使用旧版本号编辑 | 409，数据库内容不被覆盖 |
| 编辑审核中或已发布文章 | 409 |
| 删除已发布文章 | 409，提示先下架 |
| 查询超大页大小 | 400 或按明确上限处理 |
| 非法排序字段 | 400，不拼接进入 SQL |
| 查询无结果 | 返回空列表和总数 0 |
| 提交包含危险脚本的正文 | 清洗或拒绝，公开输出不能执行脚本 |

## 11 验收标准

- 可以完成新增、详情、编辑、删除、分页和组合查询。
- 文章作者来自当前登录用户，不能由请求伪造。
- 分类无效时不能保存文章。
- 并发编辑不会静默覆盖。
- 非法状态文章不能编辑或删除。
- 分页排序稳定，非法排序字段不会进入 SQL。
- 文章列表不存在明显 N+1 查询。
- 富文本安全策略有代码、测试和说明。
- 关键操作具有权限校验和操作日志。

## 12 不在本阶段范围

- 实时协同编辑。
- 完整正文版本对比和恢复。
- 多语言文章和跨站点复用。
- 动态字段模型、SEO 套件和页面搭建器。
- 完整素材库和视频处理。
