# 用户认证与账号管理模块需求分析

| 项目 | 内容 |
| --- | --- |
| 模块负责人 | B |
| 主要参与者 | 未登录访客、普通用户、管理员 |
| 上游依赖 | 统一响应、统一异常、数据库连接 |
| 下游使用方 | 角色权限、文章、审核发布、操作日志 |

## 1 模块目标

本模块负责确认“当前请求是谁发起的”，并管理账号的基本生命周期。它不负责决定用户能执行哪些具体业务操作，具体授权由角色权限模块完成。

模块必须完成注册、登录、退出、当前用户查询、用户分页查询和账号启停，并保证密码、会话和账号状态不会被客户端绕过。

## 2 业务参与者

| 参与者 | 可以执行的操作 |
| --- | --- |
| 未登录访客 | 注册、登录 |
| 已登录用户 | 退出、查询自己的基本信息和有效权限 |
| 管理员 | 查询用户、查看账号状态、启用或停用账号 |

## 3 功能需求

| 编号 | 优先级 | 需求 | 业务结果 |
| --- | --- | --- | --- |
| AUTH-01 | P0 | 用户注册 | 创建有效普通账号并分配默认角色 |
| AUTH-02 | P0 | 用户登录 | 验证账号与密码，创建登录会话 |
| AUTH-03 | P0 | 用户退出 | 当前会话失效 |
| AUTH-04 | P0 | 查询当前用户 | 返回用户基本信息和当前有效权限 |
| AUTH-05 | P0 | 用户分页查询 | 按用户名、账号状态和创建时间查询 |
| AUTH-06 | P0 | 账号启停 | 管理员启用或停用指定账号 |
| AUTH-07 | P0 | 密码安全 | 密码只以安全摘要保存和校验 |
| AUTH-08 | P1 | 修改本人密码 | 校验原密码后修改并使旧会话按约定失效 |

## 4 注册规则

1. 用户名为必填项，去除首尾空白后仍不能为空。
2. 用户名长度和允许字符由数据字典统一规定，数据库必须提供唯一约束。
3. 密码必须满足最低长度要求；课程演示数据也不能使用明文入库。
4. 注册请求即使携带角色、权限或账号状态字段，也不得据此获得额外权限。
5. 注册成功后分配系统配置的默认角色；默认角色不存在时注册失败，不能创建无确定权限边界的账号。
6. 重复用户名返回 409；并发注册仍由数据库唯一约束兜底。
7. 响应不得返回密码、密码摘要或内部会话标识。

## 5 登录规则

1. 登录需要用户名和密码。
2. 用户不存在、密码错误和账号不可用时均拒绝登录；对外提示不应帮助枚举有效账号。
3. 账号状态为停用或已删除时不能登录。
4. 登录成功后建立新的会话，并保存必要的用户标识。
5. 当前用户和权限应在服务端获取，不能信任请求头或请求体中的用户 ID。
6. 登录成功和失败均允许记录安全日志，但日志不得包含密码。
7. 多次连续失败是否限制登录属于 P1；若未实现，应在报告中说明范围。

## 6 退出和会话规则

1. 退出只终止当前会话，不修改账号本身。
2. 退出成功后，使用原会话访问受保护接口返回 401。
3. 重复退出应安全处理，不产生服务端异常。
4. 账号被停用后，后续受保护请求必须失效；允许采用“下一次请求重新检查账号状态”的课程实现。
5. 角色或权限变更后的生效时机必须统一。推荐下一次请求生效，避免必须重新登录才能验证授权变化。
6. 会话标识不得出现在业务日志、错误响应或普通查询结果中。

## 7 当前用户查询

返回内容至少包括：

- 用户 ID。
- 用户名和展示名称。
- 账号状态。
- 角色编码集合。
- 有效权限编码集合。

不得返回密码摘要、登录失败次数、内部会话对象或无关管理字段。

## 8 用户管理规则

1. 用户列表只有具备 `cms:user:read` 权限的用户可以访问。
2. 查询条件包括用户名模糊匹配、账号状态和创建时间范围。
3. 用户列表必须使用数据库分页，并使用稳定排序。
4. 账号启停需要 `cms:user:manage` 权限。
5. 管理员不能通过普通资料编辑接口修改用户角色；角色变更必须走角色分配接口。
6. 是否允许管理员停用自己必须明确。课程 MVP 建议拒绝，防止唯一管理账号失效。
7. 停用用户不删除其历史文章、审核记录和操作日志。

## 9 异常与边界场景

| 场景 | 预期结果 |
| --- | --- |
| 用户名为空或格式不合法 | 400，返回字段校验信息 |
| 两个请求同时注册相同用户名 | 仅一个成功，另一个返回 409 |
| 请求注册为管理员 | 忽略管理字段，仅分配默认角色 |
| 用户不存在或密码错误 | 拒绝登录，不返回内部判断细节 |
| 停用账号登录 | 拒绝登录 |
| 未登录查询当前用户 | 401 |
| 普通用户查询用户列表 | 403 |
| 退出后继续请求 | 401 |
| 管理员停用自己 | 409 或明确业务错误，账号保持有效 |

## 10 验收标准

- 注册、登录、退出和当前用户查询可以连续演示。
- 数据库中不存在明文密码，接口和日志不返回密码摘要。
- 停用账号无法登录，已有会话按约定失效。
- 用户分页、组合筛选和稳定排序结果正确。
- 普通用户无法调用用户管理接口。
- 重复注册、非法参数、错误密码和会话失效用例均有 ApiFox 记录。

## 11 不在本阶段范围

- 邮箱或短信验证码。
- 第三方登录、企业单点登录和多因素认证。
- 找回密码邮件流程。
- 跨设备会话管理和登录风险评分。
