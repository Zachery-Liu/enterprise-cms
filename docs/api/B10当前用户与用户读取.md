# B-10 当前用户与用户读取

日期：2026-10-08。按 V1.0 公共契约实现，公共类型完整类名和字段保持不变。

## 当前用户接口

`GET /api/auth/me` 要求有效登录会话，不额外要求管理权限，也不要求 CSRF Token。成功返回 `ApiResponse<CurrentUser>`，响应设置 `Cache-Control: no-store`。

```json
{
  "code": "OK",
  "message": "成功",
  "data": {
    "userId": 12,
    "username": "editor_demo",
    "displayName": "编辑演示",
    "status": "ACTIVE",
    "roleCodes": ["EDITOR"],
    "permissionCodes": ["cms:article:read"]
  },
  "requestId": "example-request-id"
}
```

上例用户及权限仅用于展示响应形状，不表示演示账号的实际授权。roleCodes 和 permissionCodes 是去重、按编码排序的数组，仅含有效角色和权限；无角色的有效账号返回空数组。响应不含密码摘要、会话标识或持久层管理字段。

未登录、会话失效、账号停用或逻辑删除返回 401。每次后台请求重新验证账号；角色和权限在当前请求首次读取上下文时查询，不跨请求缓存。修改授权后下一请求读取新结果。`userId` 查询参数、请求头及客户端提供的角色不能替换真实身份。

## A 获取当前操作者

依赖注入 `com.zachery.cms.common.context.CurrentUserContext`，业务中调用：

```java
CurrentUser actor = currentUserContext.getRequiredUser();
Long authorId = actor.userId();
// 将 authorId 用作服务端确认的作者、审核人或更新人。
```

`CurrentUser`、`UserStatus` 和 `CurrentUserContext` 位于 `com.zachery.cms.common.context`。`UserStatus` 为 ACTIVE、DISABLED。CurrentUser 的两个集合不可修改，并防御性复制构造参数。

`getCurrentUser()` 在无身份上下文时返回 `Optional.empty()`；`getRequiredUser()` 抛出统一 `AUTH_UNAUTHENTICATED` 异常。受保护 Controller 必须位于当前认证拦截器覆盖的 `/api/**` 路径。匿名入口当前不建立操作者上下文，即便携带已有 Cookie 也不自动提升为受认证入口。

同一请求内重复获取使用同一个不可变快照；请求结束或异常后清理请求属性。后台任务和另建线程没有默认用户身份，不能通过手工写 ThreadLocal 或接收客户端 ID 来冒充操作者。Spring MVC 异步业务的身份传递需单独设计，当前交付不提供这种传递能力。

持久层 `SessionAuditActorProvider` 从相同的已认证请求主体读取 ID，供 MyBatis-Plus 自动填充 createdBy、updatedBy；读取操作者本身不查询数据库。匿名注册和后台工作保留无操作者语义。A 仍需从可信上下文组装自己的业务字段，不可把客户端 createdBy 等字段直接映射为可信值。

## A 批量读取文章作者

注入 `com.zachery.cms.modules.identity.user.service.UserReader`；返回值 `UserSummary` 也在该包内，仅含 id、username、displayName、UserStatus status。

```java
List<Long> authorIds = articles.stream().map(ArticleView::authorId).toList();
Map<Long, UserSummary> authors = userReader.findByIds(authorIds);
// 随后在内存中通过 authors.get(article.authorId()) 组装每篇文章。
// 返回 null 时，使用“未知用户”占位；不要在循环中再查询数据库。
```

`articles`、`ArticleView` 为调用方示意类型，非 B 新增类型。

| 输入或数据状态 | 行为 |
| --- | --- |
| 空集合 | 空 Map，不执行 SQL |
| 重复 ID | 自动去重，按首次出现顺序返回找到的用户 |
| null 集合、null 元素、非正 ID | 统一参数校验异常 |
| 原始集合超过 500 项（包括重复项） | 统一参数校验异常 |
| ACTIVE 账号 | 返回展示信息 |
| DISABLED 账号 | 仍返回展示信息和 DISABLED 状态，保留历史作者 |
| 已逻辑删除或不存在账号 | Map 中不生成记录，由 A 使用“未知用户”占位 |

返回 Map 不可修改。非空有效批量输入执行一条参数化 SQL，只选取四个展示字段，不读取 password_hash、角色或会话。该接口是 Java 内部只读公共能力，不新增 HTTP 用户枚举接口；A 负责其文章接口的访问控制和作者信息展示范围。
